# BVB-007 — Offline faucet prototype

Development only. Run from repository root: `python3 -m unittest discover -s tests -v`. No dependencies outside the Python standard library. No server, real addresses, RPC, or blockchain transactions. Only Denzuve synthetic addresses are accepted. Other currency names are registry placeholders.

SQLite stores available synthetic funds and reserves claims atomically; simulated receipts are idempotent and persisted. The 100-unit payout and 24-hour cooldown are test fixtures, not approved production parameters. The clock is supplied by the test caller, not suitable for a public endpoint. No actual mining reward scanner, fee accounting, network validation, CAPTCHA, public API, authenticated administration, or cross-process real wallet reconciliation yet. Future production architecture must isolate web intake from signing and reconcile ambiguous broadcast results before retrying. No production deployment or mining changes authorised by this checkpoint. Proposed mining-time split remains 35/35/30, not activated.

Qualification: run unit tests and review results before merging. Further concurrency, crash recovery, adversarial, real-network and sustained-operation tests required before live service.
